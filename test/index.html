This is a pretend "client website"

It has nothing to do with LeadRyze itself — it's just a plain HTML page standing in for the kind of external site a tenant would actually embed the widget on. If everything is wired up correctly, a chat bubble should appear in the bottom-right corner a moment after this page loads.

Before this will work: in LeadRyze → Configuration Hub → AI Chatbot Widget, add localhost as an Allowed Domain and save — a locally-served test page like this one sends Origin: http://localhost:<port>, and the widget's own CORS check matches on hostname only (ignores the port).
